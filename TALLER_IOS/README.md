# Taller en clase

**Propósito**
Crear un nuevo template para router C3725, cargado sobre MV - no en server local -.

**Descripción**

Implementar el tema explicado en clase, como preámbulo a la carga de un *appliance* como FortiGate, el cual requiere que se tenga habilitada la MV de GNS3.

**Entrega**

Crear individualmente una carpeta con la nomenclatura **NombreApellido** y en ella, mediante un `README.md` enriquecido, documentar el proceso.
Se entiende como "README" enriquecido aquel que incluya imágenes, entradas de comandos por terminal, listas, etc.

## RECOMENDACIONES

* Tanto la app de GNS3 como la MV deben coincidir en su versión.
* Una vez creada la máquina, garantizar que esta suba antes de iniciar GNS3.
* Hacer uso del *wizard* de GNS3 en caso de requerir reconfigurar la conexión entre GNS3 y la MV GNS3.
