# Guías.

- https://ciberseguridad.blog/creando-nuestro-laboratorio-de-fortigate-en-gns3/ : El artículo expone de manera integral el procedimiento para desplegar un firewall FortiGate en el emulador de redes GNS3 mediante una imagen KVM gratuita, guiando desde la instalación y resolución de limitaciones de rendimiento por virtualización anidada, hasta la puesta en marcha de un laboratorio funcional que incluye el cambio de credenciales por consola, el direccionamiento y habilitación de acceso web en la interfaz LAN, la conexión WAN mediante DHCP, y la posterior configuración de políticas de seguridad con NAT para permitir y auditar la navegación hacia Internet de los equipos clientes de la red interna.
- https://github.com/Abbas310/fortigate-homelab : El repositorio fortigate-homelab de Abbas310 documenta el despliegue práctico de un entorno de laboratorio corporativo con un firewall virtual FortiGate (FortiOS) sobre VMware Workstation, abarcando desde la configuración de redes virtuales segmentadas (WAN puenteada y LAN aislada) y la activación de licencias gratuitas mediante sincronización horaria por NTP, hasta la implementación de un servidor DHCP interno y políticas de firewall con traducción NAT para otorgar y asegurar la navegación hacia Internet de un cliente Windows 10, complementado con una guía detallada de resolución de fallas en capa 2, enrutamiento y resolución DNS.
- https://github.com/Abbas310/fortigate-homelab :El repositorio documenta el despliegue de un laboratorio con un firewall virtual FortiGate en VMware Workstation, detallando la segmentación entre una red WAN en puente y una LAN aislada, la activación de la licencia gratuita, y la configuración de DHCP y políticas de seguridad con NAT para brindar salida controlada a Internet a un cliente Windows, junto con soluciones a fallas comunes de conectividad y DNS.
- https://hegdepavankumar.github.io/Fortigate-Firewall-Complete-Guide/  : **Guía Completa**La guía completa de FortiGate desarrollada por Hegde Pavan Kumar constituye un manual integral de laboratorio y referencia técnica sobre FortiOS (versión v7.0.9 simulada en entornos EVE-NG y VMware Workstation), estructurada en módulos progresivos que abarcan desde los fundamentos de arquitecturas UTM (NGFW) y acceso por interfaz gráfica/CLI, hasta configuraciones avanzadas de políticas de firewall, alta disponibilidad (HA), perfiles de seguridad unificada (IPS, Antivirus, Filtrado Web, Control de Aplicaciones), autenticación de usuarios integrada con Active Directory, VPNs (IPsec y SSL) y prácticas de monitoreo y auditoría mediante registros
- https://github.com/meirza23/fortigate-ha-zerotrust-lab  :  El repositorio fortigate-ha-zerotrust-lab de Meirza documenta la implementación de un **laboratorio enfocado en la alta disponibilidad (HA) de firewalls FortiGate junto con una arquitectura de red basada en Zero Trust (ZTNA)**, cubriendo el diseño de topología redundante, la sincronización entre nodos en clúster y la aplicación de políticas de acceso de mínimo privilegio e inspección continua de endpoints.
- https://medium.com/@dhruvpatel1112002/%EF%B8%8F-part-2-syslog-integration-with-fortigate-firewall-on-ubuntu-soc-home-lab-5e2be4f4af7e
